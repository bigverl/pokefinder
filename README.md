# PokeFinder

Pokedex-style tool for use with pokerogue.

Features:
- Candidate Finder: Find pokemon by filtering for stats, type matchup, moves
- Pokedex: Classic pokedex with basic Pokemon information including name, height, weight, description
- Type Coverage Analyzer: Find out where your chosen team's strengths and weaknesses are!
