# PokeFinder

A team building tool for PokeRogue. Search for Pokemon by move, type, and stats. Analyze your team's offensive and defensive type coverage.

## Features

- **Candidate Finder** — Search for Pokemon by stats, type matchups, and moves
- **Type Coverage Analyzer** — Find your team's offensive and defensive coverage gaps

---

## Stack

- Backend: Litestar (Python 3.12+), JSON fixtures, uv
- Frontend: React + TypeScript (Vite)
- Hosting: Railway

---

## Prerequisites

- [Python 3.12+](https://www.python.org/downloads/)
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [just](https://github.com/casey/just#installation)
- [Node.js 20+](https://nodejs.org/)

---

## Quickstart

```bash
just install
just start
```

Open http://localhost:5173 in your browser.

```bash
just stop
```
